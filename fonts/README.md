# 图标字体

`materialdesignicons-webfont.ttf` 是随模板分发的 Material Design Icons Webfont 文件。模板通过 `preamble.tex` 的 `\MaterialDesignIcons` 字体族和按码点命名的宏调用它。

- 来源：[Templarian/MaterialDesign-Webfont](https://github.com/Templarian/MaterialDesign-Webfont)
- 字体文件：[materialdesignicons-webfont.ttf](https://github.com/Templarian/MaterialDesign-Webfont/blob/master/fonts/materialdesignicons-webfont.ttf)
- 许可：Apache License 2.0，见 `licenses/MaterialDesign-Webfont-NOTICE.txt`

正式稿只需保留实际使用的图标宏；不要把图标字体设为正文或标题字体。
