# 中文书籍模板：平面计划

以下页型以当前样张的章、课层级为示例；页型本身可以复用于部分、章、节等其他目录结构。

## 前置页

| 页序 | 页面类型 | 版面任务 |
|---|---|---|
| 1 | 封面 | 主标题、副标题、出版信息和封面图像位置 |
| 2 | 封面内页（扉页） | 书名、作者、版本和出版信息 |
| 3 | 前言 | 前言标题、阅读引子或版本说明 |
| 4 | 目录 | 章、课、课内标题三级导航 |

## 正文页

| 页面类型 | 使用场景 | 主要元素 |
|---|---|---|
| C01 章首页 | 每章开头 | 独立页面，“第 X 章”编号块、章名、章图像、章导言 |
| L01 课首页 | 每课开头 | 按剩余空间接排或换页，“第 X 课”编号块、课名、课导言 |
| B01 正文页 | 连续论证 | 正文、一级课内标题、页眉和外侧页码 |
| M01 材料页 | 图像、档案、图表 | 图像模块、图注、材料说明 |
| K01 栏目页 | 阅读问题或原典 | 浅色底、可见栏目标题、短材料 |
| T01 链接段 | 跨节回收 | 三菱形、细虚线、具体交叉指向 |

## 节奏规则

- 章首页和课首页承担导航，正文从下一行进入对象和论证。
- 栏目出现前后各保留连续正文，栏目不连续堆叠。
- 图像的尺寸取版心的 1/3、1/2 或 2/3，图注紧随图像。
- 表格只比较具有共同尺度的项目，表头和表尾使用细线。
- 章节末尾让结论落在正文段落中，避免单独留下标题或一行文字。
